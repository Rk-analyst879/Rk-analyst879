* **Инструменты:** SQL (PostgreSQL), учебная база Chinook.
* **Что сделано:**
    - Проведен анализ выручки по странам и городам.
    - Выявлены ТОП-10 самых прибыльных категорий товаров.

* **Статус:** Изучаю оконные функции для реализации.
